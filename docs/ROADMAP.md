# 开发路线图

> 项目：Windows_AI 桌面看板娘（桌宠）
> 版本：v0.1.0

---

## 项目愿景

打造一款功能完善、交互丰富的桌面看板娘应用，支持AI对话、立绘切换、语音交互等核心功能。

---

## 架构演进路线

### 阶段1：模块化（当前）

```
CharacterWidget ──▶ LLMService ──▶ ConfigManager
                    ──▶ BubbleWidget
```

### 阶段2：服务化（v0.2.0-v0.3.0）

```
CharacterWidget
    ├── BubbleWidget
    ├── SettingsWidget
    ├── LLMService
    ├── TTSService
    └── ConfigManager
```

### 阶段3：插件化（v0.5.0+）

```
Core
    ├── PluginManager
    ├── ConfigManager
    └── EventBus

Plugins
    ├── CharacterPlugin
    ├── LLMPlugin
    ├── TTSPlugin
    ├── WeatherPlugin
    └── SchedulePlugin
```

## 风险评估

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|----------|
| DeepSeek API变更 | AI对话功能失效 | 中 | 封装API层，便于适配 |
| TTS服务不可用 | 语音功能失效 | 低 | 支持多TTS引擎切换 |
| 立绘资源过大 | 打包体积增加 | 中 | 支持资源按需加载 |
| 网络延迟 | 用户体验下降 | 中 | 添加加载状态提示 |
